# ComicCraft — AI Comic Story Creator

ComicCraft is a FastAPI web application for creating AI-generated comic stories.

The application accepts:

- Story prompt
- Character name
- Setting
- Story tone
- Art style
- Number of panels

It then generates:

1. Structured comic outline
2. Narration
3. Character dialogue
4. Captions
5. Comic illustrations
6. Comic layout
7. Downloadable PDF

## Requirements

Install:

- Python 3.11+
- VS Code
- Gemini API key
- Hugging Face token if using Hugging Face image generation
