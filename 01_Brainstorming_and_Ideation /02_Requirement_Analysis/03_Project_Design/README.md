# Project Design

## System Design
ComicCraft follows a simple AI-powered workflow.

## Workflow
1. User enters a story idea.
2. AI generates the story.
3. Story is divided into comic panels.
4. AI generates images for the panels.
5. Panels are arranged into a comic.
6. User previews and exports the comic.

## Technologies
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Gemini API
